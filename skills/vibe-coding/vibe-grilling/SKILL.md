# Grilling a Plan

Interview the user relentlessly about every aspect of the topic until you reach a shared understanding. Walk down each branch of the decision tree, resolving dependencies between decisions one by one. For each question, offer your recommended answer.

Ask one question at a time and wait for the user's answer before continuing. Asking multiple questions at once is bewildering.

If a *fact* can be found by exploring the environment (filesystem, tools, etc.), look it up instead of asking. The *decisions* are the user's — put each one to them and wait.

Do not act on the outcome until the user confirms the shared understanding has been reached.
