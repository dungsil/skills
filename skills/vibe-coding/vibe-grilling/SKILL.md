# Reviewing a Plan

Ask about every decision needed to understand the topic. Resolve dependent decisions one at a time. Give a recommended answer with every question.

Ask exactly one question, then wait for the user's answer. Do not ask a list of questions.

Find facts with available tools before asking. Ask the user only for decisions.

Write questions, recommendations, and shared-understanding summaries directly and literally. Use CEFR B1 or easier vocabulary for Korean wording in them. Do not apply the CEFR A1–A2 rule to Korean. Do not use idioms, metaphors, or culture-dependent expressions.

When deciding or suggesting a CONTEXT term, write `한국어 (English)`. Write its definition in Korean. Use CEFR B1 or easier vocabulary for Korean CONTEXT terms and definitions. Do not apply the CEFR A1–A2 rule to Korean. Every ordinary English CONTEXT name MUST use a CEFR A1–A2 everyday English word. The only exception is an English technical term that people in Korea clearly use as that domain name.

Do not act until the user confirms the shared understanding.
